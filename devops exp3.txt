Procedure

1. Install Docker Desktop and ensure Docker Engine is running.
2. Create app1 as a Flask service provider application.
3. Create app2 as a service consumer application that communicates with app1.
4. Write Dockerfiles for both applications.
5. Create a docker-compose.yml file to define and run multi-container services.
6. Build Docker images using docker-compose build.
7. Run containers using docker-compose up.
8. Verify communication between containers.
9. localhost:5000

Part A - single flask container

Code:

Pg3/app.py:

from flask import Flask

app = Flask(__name__)

@app.route('/')
def home():
    return "Hello from Dockerized Flask App!"

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)

pg3/requirements.txt

flask

pg3/Dockerfile

FROM python:3.9-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
EXPOSE 5000
CMD ["python", "app.py"]

cmnds to run 

build image - docker build -t "app name" .
run container - docker run -p 5000:5000 "app name"

pgm-3_Multicontainer /docker-compose.yml

services:
  app1:
    build: ./app1
    container_name: app1
    ports:
      - "5000:5000"
  app2:
    build: ./app2
    depends_on:
      - app1

Command to run:
